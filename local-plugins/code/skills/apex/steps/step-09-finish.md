# Step 9: Finish & Create PR

Final step: shut down the team (if any), commit, push, create the PR. No code changes here.

## 1. Shutdown agent team (teams_mode only — this is the ONLY step that does it)

Send a shutdown_request via SendMessage to each teammate, wait for confirmations, then call `TeamDelete` to clean up team files and task directories. Do this BEFORE any git operations.

## 2. Git status and commit

`git status` — if uncommitted changes exist, commit them as `feat({task_id}): {task_description}`. Then show the commits that will be pushed (`git log origin/{branch_name}..HEAD --oneline`).

## 3. Push gate

- auto_mode → push directly.
- Otherwise ask via AskUserQuestion: **Push and create PR** (recommended) / **Push only** / **Review commits first** / **Cancel**.

Never force-push without an explicit user request.

```bash
git push -u origin {branch_name}
```

If the push fails, show the error and ask how to proceed.

## 4. Create the PR (pr_mode)

```bash
gh pr create --title "feat({task_id}): {task_description}" --body "..."
```

Body: `## Summary` (what was implemented), `## Changes` (key changes), `## Testing` (how it was validated), footer `_Generated by APEX workflow_`. Capture the URL with `gh pr view --json url -q '.url'` and display it.

## 5. Save and summarize

If save_mode: run the update-progress script for step 09 (in_progress, then complete) and append branch, PR URL, commits and timestamp to `{output_dir}/09-finish.md`.

Close with the completion banner: task, ID, and a checklist of what ran (analysis, plan, implementation, validation, tests/review if enabled, push, PR URL).
